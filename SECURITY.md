# Security

Please report a vulnerability privately through GitHub's **Report a vulnerability** (Security → Advisories), not in a
public issue. You'll get an answer within a week.

Especially welcome: any way an agent user can act above its level, change a level, or make a change
that the owner can't undo ([decision 0001](docs/decisions/0001-levels-are-roles.md)), or any way to get around `includes/guard.php`.
